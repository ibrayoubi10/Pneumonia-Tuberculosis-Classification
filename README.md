## 🎯 Project goal
This project is my **first full deployment of a Machine Learning model**.  
The objective is to build an end-to-end pipeline that:

1. **Starts from a Kaggle Chest X-Ray dataset** (Pneumonia & Tuberculosis).
2. **Trains a CNN model** to classify X-ray images.
3. **Deploys the model** and provides a **web interface** where users can upload an X-ray image and get a prediction.
